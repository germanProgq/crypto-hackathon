# Анализ проекта: что нужно доработать для хакатона

## Критичные несоответствия требованиям

### 🔴 КРИТИЧНО: Автоматический перенос ставок между раундами

**Проблема:**
Согласно статье о Telegram Gift Auctions (https://membertel.com/blog/telegram-gift-auctions/):
- **"Lower bids automatically carry over to the next round"** - ставки автоматически переносятся
- **"You lose a round → Your bid carries over"** - при проигрыше ставка остается активной
- **"Your Stars are locked, not spent. You stay in the auction until outbid or the round ends"** - один активный бид

**Текущее состояние:**
- Ставки привязаны к конкретному `roundIndex`
- Для участия в следующем раунде нужна **новая ставка**
- Нет механизма автоматического переноса ставок

**Что нужно сделать:**
1. Изменить модель данных для поддержки "активной ставки на аукцион" (не на раунд)
2. При финализации раунда для non-winners: автоматически создавать ставку в следующем раунде
3. Изменить логику ранжирования: учитывать "активную ставку" пользователя в текущем раунде
4. Обновить логику размещения ставок: обновление активной ставки вместо создания новой

**Приоритет:** 🔴 КРИТИЧНО - это основная механика, описанная в задании!

## Технические детали для доработки переноса ставок

### Новая модель данных

**Вариант 1: Активная ставка на аукцион**
```typescript
interface UserAuctionBid {
  auctionId: ObjectId;
  userId: string;
  amount: number;
  createdAt: Date;
  lastUpdatedAt: Date;
  // Текущий раунд определяется через auction.rounds
}

// При финализации раунда:
// 1. Winners: capture hold, удалить активную ставку
// 2. Non-winners: release hold, ставка остается активной
// 3. Следующий раунд: использует активную ставку из предыдущего
```

**Вариант 2: Ставки с флагом активности**
```typescript
interface BidDocument {
  auctionId: ObjectId;
  roundIndex: number; // раунд, в котором была создана
  userId: string;
  amount: number;
  isActive: boolean; // активна ли в текущем раунде
  carriedFromRound?: number; // из какого раунда перенесена
}
```

**Рекомендация:** Вариант 1 более соответствует описанию Telegram Gift Auctions ("one active bid per auction").
